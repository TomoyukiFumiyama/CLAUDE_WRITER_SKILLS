# ベストプラクティス記事執筆スキル

## 手順
1. references/tone-guide.md を読み込む
2. 読者の課題を再定義し、解決の全体像を示す
3. 手順を実行順で記述し、各手順の目的と失敗例を添える
4. 実行チェックリストとCTAで締める

## 最適化プロンプト
- 各手順は「目的 / 手順 / 注意点 / 成果指標」で書く
- 可能な限り具体的な数値目安を入れる
- 初心者が詰まるポイントを先回りして補足する
- 結論では「今日から実行する最初の一歩」を明記する
