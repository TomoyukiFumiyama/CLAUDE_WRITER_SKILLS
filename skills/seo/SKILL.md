# SEO最適化スキル

## チェック項目
1. タイトルタグ（30-35文字、キーワードを前方配置）
2. メタディスクリプション（80-120文字）
3. H2/H3にキーワードのバリエーションを自然に含める
4. 画像alt属性の提案
5. 内部リンク候補の提示

## 出力
- 最適化済みタイトル案（3パターン）
- メタディスクリプション案
- 見出し修正の提案リスト
