# レビュー記事アウトライン作成スキル

## 手順
1. レビュー対象・利用期間・検証条件を定義する
2. H2/H3を「結論 → 良かった点 → 気になった点 → 向いている人」で設計する
3. 主観と客観（数値・仕様）を分離して配置する
4. 読者が購入判断できる比較材料を網羅する

## 最適化プロンプト
以下の入力が揃っていれば必ず反映する:
- レビュー対象
- 利用シーン（誰が、どこで、何のために）
- 評価観点（使いやすさ、コスパ、性能など）
- 記事ゴール（購入促進、認知拡大など）

出力は次の形式で作成する:
1. 総合評価の結論（先に1-2文）
2. H2/H3アウトライン
3. 各見出しに対応する検証観点
4. メリット・デメリット整理枠
