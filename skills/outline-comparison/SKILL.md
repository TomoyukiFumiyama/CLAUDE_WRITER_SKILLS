# 比較記事アウトライン作成スキル

## 手順
1. 比較対象と読者の意思決定ポイントを明確化する
2. 比較軸（価格、機能、運用性、サポートなど）を定義する
3. H2/H3を「結論先行 → 軸別比較 → 選び方」の順で設計する
4. 最終セクションに「タイプ別おすすめ」を配置する

## 最適化プロンプト
以下の入力が揃っていれば必ず反映する:
- 比較対象（例: ツールA / ツールB）
- 想定読者（例: 中小企業のマーケ担当）
- 判断基準（例: 価格重視、機能重視）
- 記事ゴール（例: 問い合わせ、導入検討）

出力は次の形式で作成する:
1. 記事の結論（先に1-2文で提示）
2. H2/H3アウトライン
3. 各見出しで答える疑問
4. 比較表に入れる項目案
