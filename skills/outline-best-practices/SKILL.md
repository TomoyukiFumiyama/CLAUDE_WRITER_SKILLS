# ベストプラクティス記事アウトライン作成スキル

## 手順
1. 読者の現状課題と到達目標を定義する
2. H2/H3を「背景 → 手順 → 失敗例 → 成功のコツ → 実行チェックリスト」で設計する
3. 抽象論ではなく再現可能な手順単位で分解する
4. 実行時の注意点と測定指標（KPI）を明示する

## 最適化プロンプト
以下の入力が揃っていれば必ず反映する:
- テーマと対象読者
- 読者の課題
- 成功状態（どうなれば成功か）
- 具体的な制約（予算・期間・体制）

出力は次の形式で作成する:
1. 記事で達成するゴール
2. H2/H3アウトライン
3. 各手順の実行条件と注意点
4. すぐ使えるチェックリスト
