# レビュー記事執筆スキル

## 手順
1. references/tone-guide.md を読み込む
2. 総評を冒頭に置いて読者の判断コストを下げる
3. 良かった点・気になった点を具体例とセットで記述する
4. 最後に「向いている人/向いていない人」で締める

## 最適化プロンプト
- 主観コメントには必ず「利用条件」を添える
- メリット・デメリットを同じ粒度で書く
- 星評価や点数を使う場合は採点基準を明記する
- CTAは過剰に煽らず、読者の次アクションを明確化する
