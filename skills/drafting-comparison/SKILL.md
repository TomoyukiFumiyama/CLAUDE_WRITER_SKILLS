# 比較記事執筆スキル

## 手順
1. references/tone-guide.md を読み込む
2. 冒頭で比較の結論を提示し、読む価値を示す
3. 比較軸ごとに事実ベースで差分を記述する
4. 最後に読者タイプ別の推奨案を提示する

## 最適化プロンプト
- 比較軸ごとに「Aの強み / Bの強み / 選定基準」を1セットで書く
- 断定は根拠とセットで記述する
- 迷っている読者の意思決定を助ける一文を各セクション末尾に置く
- まとめでは「結局どちらを選ぶべきか」を条件分岐で示す
